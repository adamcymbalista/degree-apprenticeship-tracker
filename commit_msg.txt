Fix live scraping bugs found during verification

- robots.txt fetch used urllib's default User-Agent, which GOV.UK's WAF
  403s; robotparser treats that as "disallow everything", silently
  blocking every request. Now fetched with our real User-Agent.
- findapprenticeship.service.gov.uk search is exact-phrase, not topic
  search; config.yaml subjects list replaced with confirmed single-word
  terms.
- Vacancy URL pattern corrected from /apprenticeship/reference/<id> to
  the real /apprenticeship/VAC<id>.
- Field label/value text was being split across lines by inline <b>
  tags in the real markup; block-text extraction rewritten.
- sources table was never actually written to (dead code wired up).
- venv/ added to .gitignore.

Verified end-to-end on a live run: 158 raw results, 149 after
deduplication, all correctly parsed, stored and scored.
